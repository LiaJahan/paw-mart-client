Paw-Mart is a website dedicated to pet adoption and pet accessories. Users can browse available pets for adoption and purchase accessories for their pets. Full access to the platform requires a valid user account.


-----------------------------------------------------------------------------------------------

# Features

1.  Browse and check available pets for adoption
2.  Purchase pet accessories (like : toys and foods)
3.  User authentication and account management
4.  Responsive and interactive UI, URL : http://localhost:5173/

-----------------------------------------------------------------------------------------------

# Technologies Used
Frontend: JavaScript, React
Backend: Node.js, Express
Database: MongoDB
Other: CORS for cross-origin requests, RESTful APIs for server-client communication
